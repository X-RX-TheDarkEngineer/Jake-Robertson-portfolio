# Electric Blue Dragon — AI Portfolio

Jake Robertson's AI portfolio site. Cinematic, dark, minimalistic and clean.

**Goal:** to become an AI Engineer and Software Engineer — evaluating AI systems, testing models, refining prompts, and turning raw data into reliable, human-centred products.

## What's in it

- Hero with the Electric Blue Dragon emblem and looping dragon video
- About Me — Data Specialist / AI Trainer
- Resume / Skills
- Projects — ABYSS, GRAVITY, and STRATA, Decent Sampler virtual instruments, with their actual interface panels and concept artwork
- Hobbies
- Contact
- A client-side chatbot that answers only from the content on this page

## Tech

Plain HTML, CSS, and JavaScript. No build step. Open `index.html` in a browser, or serve the folder with any static host (for example GitHub Pages).
